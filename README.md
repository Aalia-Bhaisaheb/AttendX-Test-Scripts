# AttendX-Test-Scripts

## Objective
To demonstrate version control of sample automated tests
for a student attendance application using Git and GitHub.

## Files

- test_login.py: Tests valid login, invalid password,
  and empty login fields.
- test_attendance.py: Tests attendance marking,
  empty student ID, and invalid attendance status.

## Requirements
- Python 3
- Git

## How to Run

Run the login tests:

    python -m unittest test_login.py -v

Run the attendance tests:


    python -m unittest test_attendance.py -v

## Note
These scripts test sample Python functions. They are
not integrated with a real AttendX application.

Updated directly on GitHub for pull demonstration.
